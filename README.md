# 🛒 Quicklist

Uma aplicação simples e intuitiva para criar e gerenciar uma lista de compras.

O projeto foi desenvolvido como parte dos meus estudos em desenvolvimento web, com foco em **HTML, CSS e JavaScript**, praticando manipulação do DOM, eventos e criação dinâmica de elementos.

Link do Projeto: https://marcelrezende.github.io/Lista-de-Compras---JS/

## 🚀 Funcionalidades

- ✅ Adicionar novos itens à lista
- 🗑️ Remover itens
- ☑️ Marcar itens como concluídos
- ⚠️ Validação dos itens adicionados
- 🔔 Exibição de mensagem após remover um item
- ⏱️ Mensagem de remoção desaparece automaticamente
- 📱 Layout responsivo para diferentes tamanhos de tela

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts

## 📚 Conceitos praticados

Durante o desenvolvimento, foram praticados conceitos importantes de JavaScript, como:

- `querySelector()`
- `querySelectorAll()`
- `addEventListener()`
- `createElement()`
- `append()`
- `textContent`
- `classList.add()`
- `classList.remove()`
- `remove()`
- `parentElement`
- `forEach()`
- `if`
- `setTimeout()`
- Manipulação do DOM
- Eventos de clique
- Validação de formulários

## 🎨 Interface

O projeto possui uma interface simples, limpa e responsiva, adaptada para dispositivos desktop e mobile.
